# 📆 Calendar App

Календар для створення, редагування, перетягування та видалення подій з модальним вікном та підтримкою різних представлень (Month, Week, Day, Agenda). Оформлення повністю відповідає наданому макету.

## 🔧 Технології

- React
- TypeScript
- SCSS Modules
- FullCalendar
- GitHub Pages
